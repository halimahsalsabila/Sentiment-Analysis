# Sentiment-Analysis
Sentiment analysis terkait respon pembeli tiket konser day6 di Indonesia pada platfrom X
Analisis sentimen dilakukan dengan menerapkan ensemble learning pada algoritma K-Nearest Neighbor (KNN) dan Support Vector Machine (SVM) dengan Radial Basis Function (RBF) Kernel. Kombinasi kedua metode ini bertujuan meningkatkan kinerja klasifikasi sentimen dengan memanfaatkan kelebihan KNN yang sederhana namun efektif serta SVM-RBF yang mampu memisahkan data non-linear secara optimal. Pendekatan ensemble diharapkan menghasilkan performa lebih baik dibandingkan penggunaan metode tunggal dalam hal akurasi, presisi, recall, dan f1-score.
